What these results mean

This section checks whether AI can reach the selected pages and read their information. It does not yet assess whether that information is complete, accurate or strong enough to support a recommendation.

How this would be checked in a real audit
Website permission: Read each relevant search crawler’s published access rules. A rule is not proof of an actual visit.
Finding a page: Run recorded search tests for each platform and check whether the selected URL is returned.
Reading a page: Ask the platform’s available web tool to open that exact URL and record whether the expected page content is returned.
Google / Gemini: Identify the exact product and search tool tested. Googlebot permissions for Google Search do not establish access for every Gemini tool.
Unknowns: A failed test does not prove the website blocks the AI. Results apply to the tools, pages and time tested. Server logs or owner search tools can provide additional confirmation.
